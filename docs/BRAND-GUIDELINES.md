# 🎨 Paleta de Cores — Casamento Tema Fúcsia

## Visão geral

A identidade visual do casamento deve utilizar o **fúcsia como cor principal**, transmitindo:

- elegância;
- romantismo;
- sofisticação;
- delicadeza;
- modernidade;
- sensação premium.

O fúcsia pode aparecer em diferentes intensidades, desde tons mais vivos até versões suaves, escuras e metalizadas.

A identidade visual não deve parecer infantil, excessivamente rosa ou saturada.

---

# 1. 🌺 Cores principais

Estas são as cores principais da identidade visual.

| Nome                | Hex       | Uso recomendado                               |
| ------------------- | --------- | --------------------------------------------- |
| **Fúcsia Clássico** | `#D1007A` | Cor principal da identidade                   |
| **Magenta Rosado**  | `#C21878` | Elementos secundários e detalhes              |
| **Pink Vibrante**   | `#E91E8F` | Destaques pontuais                            |
| **Framboesa**       | `#B2125B` | Títulos, textos e contraste                   |
| **Orquídea Fúcsia** | `#D94AA8` | Elementos românticos e florais                |
| **Fúcsia Suave**    | `#E87BB7` | Elementos delicados e backgrounds secundários |

### Hierarquia recomendada

```text
Cor principal:
#D1007A

Cor secundária:
#C21878

Cor de destaque:
#E91E8F

Cor escura:
#B2125B

Cor intermediária:
#D94AA8

Cor suave:
#E87BB7
```

---

# 2. ✨ Tons metalizados

O casamento deve utilizar versões metalizadas do fúcsia principalmente em:

- nomes dos noivos;
- monogramas;
- bordas;
- linhas decorativas;
- ícones;
- detalhes ornamentais;
- botões especiais;
- títulos;
- elementos de destaque.

## Paleta metalizada

| Nome                  | Base aproximada | Uso                           |
| --------------------- | --------------- | ----------------------------- |
| **Fúcsia Metalizado** | `#C73D8B`       | Principal acabamento metálico |
| **Rosé Fúcsia**       | `#D96AA5`       | Acabamento delicado           |
| **Berry Metal**       | `#A94B7A`       | Contraste sofisticado         |
| **Pink Foil**         | `#E06AAE`       | Detalhes luminosos            |

> **Importante:** cores metalizadas não devem ser representadas apenas por uma cor sólida.

Para interfaces digitais, utilizar **gradientes, brilhos e pequenas variações tonais** para criar sensação de metal, foil ou hot stamping.

---

# 3. ✨ Gradiente Fúcsia Metalizado

Gradiente recomendado para textos, monogramas e detalhes premium:

```css
linear-gradient(
  135deg,
  #8F1D5C 0%,
  #C73D8B 20%,
  #F18BC5 45%,
  #D94AA8 60%,
  #A32970 80%,
  #E06AAE 100%
)
```

Uma versão mais delicada:

```css
linear-gradient(
  135deg,
  #B72F78,
  #E87BB7,
  #F4B6D5,
  #D94AA8,
  #A94B7A
)
```

Uma versão mais luxuosa:

```css
linear-gradient(
  120deg,
  #86194F 0%,
  #B92F77 25%,
  #F59BCB 47%,
  #C73D8B 68%,
  #8C245C 100%
)
```

# 4. 🤍 Backgrounds principais

Os backgrounds devem ser predominantemente claros, elegantes e discretos para permitir que o fúcsia tenha destaque.

| Nome             | Hex       | Característica             |
| ---------------- | --------- | -------------------------- |
| **Off White**    | `#FAF7F2` | Clássico e elegante        |
| **Marfim**       | `#FFF8E7` | Tradicional para casamento |
| **Champagne**    | `#F3E5C8` | Sofisticado e quente       |
| **Blush Nude**   | `#F6E8EA` | Romântico                  |
| **Areia Clara**  | `#E9DED2` | Natural e refinado         |
| **Cinza Pérola** | `#E6E4E7` | Moderno e sofisticado      |

---

# 5. 🕊️ Background principal recomendado

Para páginas principais do site e convites:

```css
background: #faf7f2;
```

Esse tom deve funcionar como a principal base visual.

Ele cria contraste elegante com o fúcsia sem utilizar branco puro.

---

# 6. 🌷 Background romântico

Pode ser utilizado em seções especiais:

```css
background: #f6e8ea;
```

Ideal para:

- história do casal;
- galeria;
- mensagens;
- lista de presentes;
- detalhes da cerimônia.

---

# 7. 🥂 Background Champagne

Para elementos que precisam transmitir luxo:

```css
background: #f3e5c8;
```

Ideal para:

- cards;
- detalhes premium;
- caixas de informações;
- menus;
- convites digitais;
- seções de destaque.

---

| **Grafite Quente** | `#332C30` |
| **Cinza Elegante** | `#51484C` |

```css

```

### Títulos escuros

```css
color: #5a1837;
```

---

# 9. 🥇 Dourado complementar

O dourado pode ser utilizado com bastante moderação.

```text
Champagne Gold: #C8A46B
Soft Gold:      #D6B77C
Light Gold:     #E7D3AA
```

O dourado deve aparecer apenas em:

- linhas;
- bordas;
- pequenos ícones;
- monogramas;
- ornamentos;
- detalhes finos.

Evitar grandes blocos dourados.

# 11. 🎨 Proporção das cores

Utilizar aproximadamente:

```text
60% — Backgrounds neutros
25% — Tons claros e complementares
10% — Fúcsia
5%  — Fúcsia metalizado / dourado / detalhes
```

O fúcsia deve ser uma **cor de identidade e destaque**, não ocupar toda a composição.

---

# 12. 🌸 Direção artística

A estética deve remeter a:

- casamento sofisticado;
- editorial de casamento;
- convite premium;
- flores delicadas;
- papel texturizado;
- hot stamping;
- foil metálico;
- champagne;
- porcelana;
- seda;
- cetim;
- iluminação suave.

---

# 13. 🚫 Evitar

Não utilizar:

- rosa neon em excesso;
- pink fluorescente;
- roxo muito saturado;
- backgrounds completamente fúcsia;
- excesso de dourado;
- excesso de brilho;
- aparência infantil;
- estética Barbie;
- gradientes arco-íris;
- sombras pesadas;
- excesso de elementos decorativos.

---

# 16. Regra principal para o agente

> Sempre priorizar uma estética elegante, delicada, romântica e sofisticada.
> O fúcsia representa a identidade do casamento, mas deve ser equilibrado com backgrounds claros como off-white, marfim, champagne e blush nude.
>
> Sempre que houver elementos especiais como nomes dos noivos, monogramas ou detalhes decorativos, considerar utilizar **fúcsia metalizado, foil ou gradientes sutis**, evitando cores chapadas excessivamente fortes.
>
> O resultado deve parecer um **convite de casamento premium e contemporâneo**, e não uma interface convencional de aplicativo.
